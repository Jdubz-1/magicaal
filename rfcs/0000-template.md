## Detailed Design

> This is the main body of the RFC. Explain the design in sufficient detail that:
> - Someone unfamiliar with the codebase could implement it
> - Someone reading this RFC later can understand why the design is the way it is
>
> Include:
> - New types, interfaces, or schemas (use TypeScript for interface definitions)
> - API route additions or changes (method, path, request/response shape)
> - Engine or runtime behavior changes
> - Node type additions or modifications

> - Migration path for existing deployments (schema migrations, config changes)
> - Examples showing the feature in use
